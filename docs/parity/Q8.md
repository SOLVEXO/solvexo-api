# Q8 — Social creatives (ad-designer lite)

Web-only feature, no backend and no external service. Seller dashboard: **Social creatives** (`/store/:id/creatives`, permission `marketing.manage`).

- Pick an active product (search, first 50 matches) and a size: square 1080x1080, story 1080x1920, banner 1200x628, WhatsApp status 1080x1920.
- The browser canvas composes the product photo, name (max 3-4 lines, cut with "…"), price in the store currency, the store logo (or store name) on a panel in the store accent colour (checkout branding colour, editable; only `#rrggbb` accepted), plus an optional badge (24 chars).
- **Download PNG** and **Copy caption** (name, price, store name, product link built with the store's live address).
- Code: `web/.../StoreSection/creatives/creativeCanvas.ts` (pure drawing + helpers, tested), `SocialCreatives.tsx` (page).

Not verified: real browser drawing (jsdom has no canvas; only helpers are unit-tested), PNG export when the image host sends no CORS header (the page shows an error toast and the logo/photo can be turned off), phone layout, Urdu/Arabic product names (canvas font fallback), product link opens by product id (storefront page loads by id, not tested live).
